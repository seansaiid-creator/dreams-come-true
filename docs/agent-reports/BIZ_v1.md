## 1. 수익 현황 진단

### 1-1. 현재 구조 (코드로 검증됨)
| 채널 | 상태 | 평가 |
|---|---|---|
| Kakao AdFit | 141페이지 × 4유닛(320×50 상단 / 320×100 중단 / 320×50 ×2 하단), index는 7유닛 | **유일한 실질 수익원** |
| Google AdSense | 스크립트 index·guide 2페이지만 로드, **광고 유닛 0개**(guide 1개 제외) | **사실상 수익 0원 — 방치** |
| memimo CTA | 139페이지, gtag `memimo_click` 추적 | 직접 수익 없음(자체 앱 프로모션) |

### 1-2. 핵심 문제점
1. **AdSense 완전 방치가 가장 큰 기회손실.** 승인·ads.txt까지 끝난 계정인데 유닛이 없어 수익 0원. 한국 모바일 콘텐츠 트래픽 기준 일반적으로:
   - AdFit 배너 eCPM: 대략 **₩300~1,500** 수준(저단가 고정 배너 특성) — *추정*
   - AdSense 디스플레이/인아티클 eCPM: 대략 **₩1,000~4,000**, 앵커·전면 포함 시 그 이상 — *추정*
   - 즉 동일 노출에서 AdSense가 AdFit 대비 **2~5배** 단가가 나올 가능성이 높음(꿈해몽·로또 키워드는 금융/운세 광고주 입찰이 붙는 편).
   - 예시 시나리오(순수 가정): 일 1,000 PV × 페이지당 광고 3노출 × eCPM ₩500(AdFit) = **월 ~₩45,000** vs AdSense 병행/전환 시 **월 ₩90,000~200,000** 범위 가능. 일 PV가 이보다 훨씬 적다면 절대액도 비례해 작음.
2. **AdFit 320×50 고정 배너 위주 구성은 단가·시인성 모두 최저 티어.** 320×100, 300×250(가능 시)이 일반적으로 단가가 높음.
3. **수익 이벤트 계측 부재.** memimo_click 외에 광고 노출/클릭 관련 GA4 이벤트 없음 → 페이지별 수익 기여도 판단 불가.
4. **깨진 링크 39+19종·sitemap 누락 42페이지**는 수익 문제이기도 함: 유입→404는 광고 노출 기회의 직접 손실.
5. memimo CTA가 페이지 최상단 광고 바로 아래 큰 카드로 들어가 **가장 단가 높은 first-view 지면을 무수익 CTA가 점유** 중.

## 2. 단기 수익 개선안 (0원, 즉시 — 30일 내)

### A. AdSense 유닛 설치 (최우선)
- **방안**: 전 139개 dream 페이지에 AdSense 스크립트 + 유닛 삽입. 페이지가 인라인 중복 구조이므로 일괄 sed/스크립트 삽입으로 처리 가능(기존 memimo 139페이지 일괄 삽입 전례 있음).
- **Auto ads vs 수동 유닛**:
  - *권장: 수동 인아티클/디스플레이 유닛 1~2개 + 앵커만 Auto ads로 허용.* Auto ads 전면 개방은 AdFit 4유닛과 겹치면 광고 밀도가 과해져 UX 붕괴 + 양사 정책 리스크.
  - 수동 유닛 위치: (1) 첫 h2 섹션 뒤 인아티클, (2) 본문 종료 후·푸터 전 디스플레이.
- **임팩트**: 정성적으로 현재 광고수익의 **+50~150%** 범위 기대(*추정*). / 난이도: 하(일괄 삽입 스크립트) / 선행조건: 없음(승인 완료 상태) / 리스크: 아래 C 참조.

### B. AdFit 유닛 재배치·교체
- 320×50 3개 → **320×100 또는 300×250 1~2개로 통합**(AdFit 콘솔에서 신규 유닛 생성, 0원).
- **UX 한계선**: 화면 1스크롤당 광고 1개 이하, 본문 첫 문단 위에는 광고 1개만, 총 광고(AdFit+AdSense) 페이지당 4개 이내, 콘텐츠보다 광고가 많은 화면 금지(AdSense "가치 없는 콘텐츠" 판정 사유).
- memimo 카드를 본문 하단(마지막 h2 뒤)으로 이동 → 상단 프리미엄 지면을 광고에 반환. memimo는 어차피 스크롤 완료 독자의 전환율이 더 높음.
- 임팩트: +10~30%(*추정*) / 난이도: 하 / 리스크: 낮음.

### C. AdFit·AdSense 병행 정책 리스크 (실행 전 확인 필수)
- **AdSense**: 타 네트워크 병행 자체는 허용. 단, ① 광고가 콘텐츠를 압도하는 밀도, ② AdSense 광고를 모방/혼동시키는 배치, ③ 클릭 유도 문구는 금지. → AdFit 4개 + AdSense 2개 + 앵커면 밀도 초과 우려. **AdFit을 2개로 줄이고 AdSense 2개 추가**가 안전선.
- **AdFit**: 약관상 타 광고와의 인접 배치·중복 노출 제한 조항 존재 가능 → **실행 전 AdFit 운영정책의 '타 광고 네트워크 병행' 조항 원문 확인 필요**(미확인 상태임을 명시).
- 최악 리스크: AdSense 계정 제한(복구 어려움). 따라서 초기 2주는 보수적 배치 후 정책센터 경고 여부 모니터링.

### D. 깨진 링크·sitemap 수리 (기술팀 과업이나 수익 관점 우선순위 부여)
- 404 유입 = 광고 0노출. 39+19종 링크 수리와 sitemap 42페이지 등재는 **광고 유닛 설치와 동급의 수익 과업**.

## 4. 사주 서비스 사업 모델

### 4-1. 무료 vs 유료 설계
- **무료(전환 미끼)**: 오늘의 운세 한 줄, 꿈+생년월일 조합 "오늘의 행운 요약"(자동 생성), 사주 기본 구성(오행 분포) 1회.
- **유료(심화 리포트)**: 신년/월간 종합 리포트(재물·연애·건강 섹션, 5~10페이지 분량), 꿈해몽×사주 결합 해석(차별화 포인트 — 경쟁 사주 사이트에 없는 조합), 궁합 리포트.

### 4-2. 가격대
- 시장 앵커: 포스텔러·점신 등 유료 콘텐츠 ₩3,000~15,000대.
- 제안: **심화 리포트 ₩4,900 / 프리미엄(신년·궁합) ₩9,900**. 1인 운영·무명 브랜드이므로 저가 진입 후 후기 축적.
- 결제(0원 수단): 카카오페이 송금링크·토스아이디는 간편하나 **전자상거래 신뢰도·환불 처리가 수동**. 초기 검증용으로만 쓰고, 월 판매 10건 넘으면 정식 PG(포트원 등, 건당 수수료 ~3%대) 전환 검토. 판매업 신고(통신판매업, 간이과세자 면제 여부 확인) 요건 확인 필요.

### 4-3. 전환 퍼널 (꿈해몽 트래픽 기준)
```
꿈해몽 페이지(검색 유입)
 → "이 꿈, 내 사주와 만나면?" 인라인 CTA (139페이지 일괄 삽입, memimo 전례)
 → 무료 오늘의 행운 요약 (생년월일 입력 = 마이크로 커밋)
 → 심화 리포트 유료 제안 (₩4,900)
 → 카카오톡 채널 구독 유도 (미구매자 리타겟)
```
- 가정 시나리오(*순수 추정*): 일 1,000 방문 × CTA 클릭 5% × 무료체험 40% × 유료전환 2% = 일 0.4건 ≈ **월 ~12건 × ₩4,900 ≈ ₩59,000**. 트래픽 10배면 월 60만원대. → **사주 유료화의 성패는 트래픽 규모에 종속**됨(§5 판단 근거).

### 4-4. 법적 주의사항 (1인 운영자)
- **환불**: 디지털 콘텐츠도 전자상거래법 청약철회 대상(제공 개시 전 철회 가능, 개시 후 예외 적용하려면 사전 고지+동의 필요). 환불 규정 페이지 필수.
- **표시광고법**: "재물운 상승 보장" 류 단정 표현 금지, 운세는 오락·참고용임을 명시. 쿠팡파트너스 대가성 고지 의무.
- **개인정보**: 생년월일(+출생시간)은 개인정보. 수집 항목·보관기간·파기 정책을 개인정보처리방침에 반영, 비회원 처리 후 즉시 파기 원칙 권장.

## 5. 트래픽 vs 수익화 우선순위 판단

**결론: "수익화 기반 정비(2주) → 트래픽 성장 집중"의 순차 병행. 무게중심은 트래픽.**

근거:
1. 수익 = 트래픽 × RPM. 현 트래픽 규모 미상이나 신생 정적 사이트 특성상 소규모일 확률이 높고, 소규모 트래픽에선 RPM을 3배로 올려도 절대액이 작음. 반면 AdSense 설치·배치 정비는 **1~2주 일회성 작업으로 RPM 베이스라인을 영구히 올리는 것**이므로 먼저 끝내고 트래픽에 전념하는 것이 합리적.
2. 깨진 링크·sitemap·중복 페이지 수리는 트래픽(SEO)과 수익(404 손실) 양쪽에 동시 기여 — 최우선.
3. 사주 유료화는 §4-3 시나리오처럼 트래픽 규모에 완전 종속 → 트래픽 없이 먼저 만들면 검증조차 안 됨.

**판단 보정에 필요한 GA4 지표 (실측 미확보 — 사용자 캡처 요청 목록)**:
- 일/주 활성 사용자(DAU·WAU), 총 페이지뷰
- 유입 채널 비중(organic search 비율), Search Console 연동 시 유입 키워드 상위 20개
- 페이지별 조회수 상위 20 (어느 dream 페이지가 벌어오는지)
- 평균 참여 시간, 세션당 페이지수(광고 노출 깊이 판단)
- 기기 비중(모바일 확인), 재방문율
- 기존 이벤트: memimo_click 수

기준선: **일 사용자 500명 미만이면 90일간 트래픽 성장에 80% 리소스**, 이상이면 수익화 실험 비중 상향.

- 성공 지표: 검색 유입 주간 +20% 추세, 채널 구독 100명

### 3개월차 — 사주 유료화 검증
- 심화 리포트 ₩4,900 판매 개시(초기: 카카오페이 링크, 환불규정·처리방침 정비 선행)

- AdSense/AdFit 배치 A/B 결과 반영해 최종 광고 구성 확정
- 성공 지표: 유료 첫 10건, 전환율 데이터 확보
