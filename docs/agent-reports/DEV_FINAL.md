## §4. 기획 트랙(PLAN_FINAL)·사업 트랙(BIZ_v1) 교차 확인 결과

### 4-1. [상충 → 직권 조정] CTA 파라미터 형식: DEV `?dream=slug` vs PLAN `?kw=한글&cat=8종`
- DEV_v2 응급의 "?dream= 20줄 패치"와 PLAN P0-③의 kw/cat 재설계는 **같은 지면을 다른 규격으로** 고친다 — 그대로 두면 이중 작업+링크 재치환.
- **확정**: index 핸들러는 처음부터 **kw/cat(주 규격) + ?dream=slug(레거시 호환: 기공유·기색인 URL 보존)** 둘 다 파싱. 139페이지 CTA 링크 치환은 기획 산출물(kw/cat 지정표 139건)이 나온 시점에 **한 번만** 수행. **PLAN §2-1 보안 요건을 개발 구현 필수 요건으로 채택**: kw는 textContent(전면 이스케이프)로만 렌더(index innerHTML 13곳에 원문 삽입 금지), cat 8종 화이트리스트(불일치=change), CTA 기록 시 encodeURIComponent + index 측 URLSearchParams 파싱. 모순 해소.

### 4-2. [상충 없음, 구현 방식 명확화] "마커 주석 리라이트"(PLAN §2-2) × 11ty 빌드
- 11ty 이관 후 index.html은 빌드 산출물이라 **원시 HTML 마커 리라이트는 다음 빌드에 덮인다**. 확정: 이관 전(과도기)에는 마커 리라이트 그대로, **이관 후에는 cron이 data/today.json을 갱신→재빌드**로 동일 효과. "Actions cron→변경→커밋→자동 배포"라는 PLAN 확정 방식의 본질은 유지되므로 모순 아님 — 구현 세부만 단계별로 다르다.

### 4-3. [상충 명시] AdSense 우선순위: BIZ "최우선" vs DEV "활성화 하·후순위"
- BIZ_v1은 AdSense 유닛 설치를 §2-A 최우선·1개월차 1번으로 놓았다. DEV_v2는 활성화 기여 하 + 플랫폼 전제 미확정으로 10순위로 내렸다. **이는 목적함수가 다른 것이지 사실 판단의 충돌이 아니다**: 수익 렌즈(BIZ)에선 RPM 베이스라인 정비가 최우선이 맞고, 활성화 렌즈(DEV §3, 본 라운드의 지정 기준)에선 광고는 트래픽을 만들지 않으므로 하위가 맞다.
- **조정**: AdSense 작업은 공수 1h짜리이므로 **확인 A·D 회신 즉시 응급처치와 병행 실행**(활성화 작업을 하루도 막지 않음) — 순서 논쟁 자체를 무효화한다. 단 BIZ의 전제 2건은 정정 필요: ① "guide 1개 유닛"은 오류 — 실측 유닛 0(스크립트 태그 오인), ② "선행조건 없음(승인 완료)"은 미검증 — *.vercel.app 게재 가능성은 확인 A로 확정해야 하며, 불가 시 도메인 구입(연 1.5~2.2만원)이 선행된다. PLAN P0-④(확인 후 분기·병행)와는 정합.

### 4-4. [상충 → 직권 조정] 발행 빈도·검수: DEV "매일 auto-merge 사람 개입 0" vs PLAN "주 3~5개·무검수 게시 금지"
- **확정(§2-3 반영)**: 신규 페이지는 **주 3~5회**(thin content·카니벌라이제이션 재발 방지 — PLAN P3 채택). "매일 업데이트"라는 사용자 목표는 **오늘의 꿈 회전(매일)** + 신규 발행(주 3~5)의 조합으로 충족 — 사이트는 매일 변한다. LLM 생성은 **큐 충전 단계에서만** 수행하고 사람이 전량 검수(PLAN §2-4 준수), cron의 자동 발행은 검수 완료 큐 항목에 한함 — "무검수 게시 금지"와 "사람 개입 0(발행 시점)"이 양립한다. cron 시각은 PLAN의 KST 04~05시 채택(v2의 09:00 폐기).

### 4-5. [경미 조정] Vercel Hobby 대응: DEV "Cloudflare Pages 이전 추천" vs PLAN "선제 전환 불요, 지적 시 Pro"
- **확정**: 기본은 현상 유지(선제 이전 불요 — PLAN). 단 **확인 A 결과 커스텀 도메인을 사게 되는 시점**에는 도메인이 호스트 교체를 투명하게 만들므로 그때 Cloudflare Pages(무료·상업 허용) 이전을 함께 실행한다 — Pro 월 $20는 채택하지 않는다.
- 기타 수치 통일: 깨진 절대링크·canonical은 **19**(PLAN의 "58종=39+19" 표기와 정합), sitemap 미등재는 **41파일(dream 40+index_ad_optimized)**(BRIEF·PLAN의 42는 구수치). GA4 이벤트 7종(PLAN P0-①)은 공통 스니펫이므로 11ty 템플릿에 수용 — 충돌 없음.
