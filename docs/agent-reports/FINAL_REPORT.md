**작성: PO1·PO2 합의 (8개 역할 논의 종합), 2026-09-02**
경위: 기획자·기획 검토자·개발자·개발 검토자·UI/UX 전문가·사업담당의 산출물(각 트랙 3라운드 논의 종결) → PO1 통합 초안 → PO2 전수 검증(코드 검증 6건 전부 일치) → 지적 8건 전량 반영 후 본 최종본 확정.
수치 정본: 코드에서 직접 재검증된 값 사용 — sitemap 미등재 **41**파일, canonical 404 **19**건.

## §0. 경영 요약

**현황**: "꿈해몽 행운"(https://dreams-come-true-ten.vercel.app)은 정적 HTML 145개(꿈풀이 상세 139개)를 Vercel 무료 플랜에서 운영하는 1인 사이트다. 콘텐츠 자산과 GA4 계측(전 페이지)은 갖춰졌으나, 139개 페이지의 메인 CTA("행운번호 받기")가 아무 동작 없는 빈 홈에 착지하고, 깨진 링크 39+19종과 canonical 404 19건·sitemap 누락 41건으로 검색 색인이 새고 있으며, 단가 높은 AdSense는 광고 유닛 0개로 방치돼 있다. 사용자가 요청한 매일 자동 업데이트·사주 연동은 모두 **비용 0원 범위에서 실행 가능함이 기술 검증**됐다.

**핵심 문제 3개**: ① 회유 퍼널 단절 — CTA 파라미터 처리 코드 0줄, 홈 랜덤카드 11% 확률 404 ② 검색 색인 손실 — canonical 404·sitemap 누락·네이버 채널 미등록(한국 꿈해몽 검색의 주 전장인데 미개척) ③ 수익 방치 — AdSense 노출 0 + *.vercel.app 게재 가능성 미확정.

**핵심 결정 3개**: ① CTA는 `?kw=&cat=` 규격(+레거시 호환, XSS 방어 필수)으로 139개 파일을 한 번만 열어 수리 ② "매일 업데이트" = 오늘의 꿈 매일 자동 회전(GitHub Actions) + 신규 페이지 주 3~5개(전량 사람 검수) ③ AdSense는 계정 확인 즉시 응급처치와 병행하되 광고는 "증설이 아닌 교체"(AdFit 저단가 슬롯→AdSense 인아티클, 페이지당 총량 유지).

**비용**: 기본 0원. 조건부 최대 연 약 15,000~34,000원(도메인 필요 판정 시 + LLM 유료 채택 시). 실행은 응급 1주차(순공수 2.5~3일) → 2~4주차(10~12일) → 2~3개월차 3단계.

### 1-2. 수익 현황
- 실질 수익원은 Kakao AdFit뿐(141페이지 × 4유닛, 320×50 위주 = 최저 단가 티어).
- AdSense는 스크립트만 2페이지 로드, 노출 유닛 0 — 순수 로딩 비용만 지불 중. "승인 완료" 전제는 미검증 — 확인 A(§5)로 확정 필요.
- memimo CTA 139페이지: 직접 수익 없음. first-view 인접 프리미엄 지면 점유 + 흰색 카드가 다크 테마 이물질.

## §2. 최선의 방안 — 5개 축 확정안

### 축① 코드 문제 해결·효율화

**확정안**
1. **응급처치(1주차)**: sitemap 40 등재+lastmod 실값 / canonical 19 정정+중복 4쌍 canonical 편승(card-payment-fail→failed, email-send-failed→not-sent, golden→gold, fire-dream→fire) / vercel.json 신설(-lotto 14종 등 301, 404.html) / index 파라미터 핸들러 / 기본 og:image 1장 / 택시 복붙 7파일·tooth 중복 섹션·related-links 깨진 39종 수리. 원칙: **"139개 파일은 한 번만 연다"** — user-scalable 제거·title 차별화 동일 패스에 편승.
2. **효율화(2~4주차)**: 11ty + data/dreams.json 단일 소스 이관. permalink로 URL 145개 전량 보존, sitemap·guide·searchIndex·randomPool 빌드 타임 자동 생성 → C2·C3·H1 원천 봉쇄. **검증 4단계**(URL 인벤토리 diff=0 / 메타 추출표 대조 / 링크체커 0건 / 코어 10페이지 육안) 통과 전 배포 금지.

**기각된 대안**: 수동 유지(신규 1페이지당 6곳 갱신 — 이미 붕괴 재현됨) / diff 기반 이관 검증(노이즈로 무의미 — 4단계 검증으로 대체) / Edge Middleware·서버 함수(정적·0원 전제에서 검토 가치 없음).

### 축② 매일 새 꿈풀이 자동 업데이트

**확정안**: "매일 업데이트" = **매일 회전 + 주간 발행**의 조합.
- GitHub Actions cron 1개, 매일 KST 04:30(지연 허용): "오늘의 꿈 3선+한 줄" 갱신→커밋→Vercel 자동 배포. 이관 전엔 마커 리라이트, 이관 후엔 data/today.json 갱신→재빌드(동일 효과).
- 신규 페이지는 **주 3~5개 상한**. LLM은 큐 충전 단계에서만, **사람 전량 검수 완료된 queue.json 항목만** cron이 자동 발행(무검수 게시 금지와 발행 시점 무인화가 양립). 주제는 `dream_search` result_count=0 검색어 월 1회 추출 — 사용자 수요가 편집 계획이 되는 0원 구조.
- 운영 방어: 빈 큐 스킵+잔량≤3 경고, 알림 단일 채널(텔레그램/ntfy.sh 무료), 주 1회 "오늘의 꿈 날짜" 1분 육안, 월 1회 체크리스트(Actions 60일 비활성화 연쇄 방어).

**기각된 대안**: 매일 신규 발행 auto-merge 사람 개입 0 — thin content·카니벌라이제이션 재발 + 무검수 게시 금지 원칙 위반. "사이트는 매일 변한다"는 목표는 회전으로 충족됨.

### 축③ 사주 서비스 연동

**확정안**: 포지셔닝은 "단독 사주 앱과 경쟁하지 않는 **이 꿈 × 내 사주 결합 리포트**".
- 계산: 전량 클라이언트 JS(서버 전송 없음 = 프라이버시 셀링포인트, 비용 0원). **정확도 사양 3건이 출시 게이트**: 야자시 정책(23시 이후=익일 일주, UI 명시) / 한국 DST(1948–51·55–60·87–88)+UTC+8:30 표준시(1954–61) 보정 / 절입시각 KASI 1차 출처·CST→KST +1h 강제. KASI 만세력 100케이스 검증 통과 필수.
- 콘텐츠: 일간 10 × 카테고리 8(P0 폴백 8종 재사용) = 80조합 + 일진 단문 10 = 90문안. "매일 다름" = 일진 단문+일별 번호 변동. LLM 초안+전량 사람 검수.
- 입력 UX: saju.html 단일 화면, 3-select 생년월일 + 음/양력 토글 + 12지시 칩+"몰라요"(기본) — 최대 6탭. localStorage 저장으로 재방문 시 원탭("1990년 3월 5일생 · 오늘의 사주 바로 보기") — **재방문 훅의 핵심**. 서버 전송 없음 한 줄 명시.
- 진입점 3종: 해몽 결과 하단 / dream 페이지 회유 카드(memimo 위) / 재방문자 원탭. 사주→꿈 역회유("오늘 꾸면 좋은 꿈 3선")로 상호 재방문 구조.
- **v1은 전면 무료+광고**. 유료화는 트래픽·`saju_open` 데이터 확보 후 별도 안건(§5-B-9).

**기각된 대안**: v1부터 유료 리포트 판매(₩4,900) — 성패가 트래픽 규모에 종속(사업 트랙 자체 판정)이고, 결제·환불·통신판매업 신고가 1인 운영 부담이며 기획 합의(자체 결제 금지)와 충돌.

### 축④ 서비스 활성화

**확정안 — 기여 큰 순 Top 5**:
1. **회유 루프 수리**: 139개 CTA를 `index.html?kw=<encodeURIComponent(한글)>&cat=<8종>`으로 일괄 치환. index 핸들러는 kw/cat(주 규격)+`?dream=`(레거시 호환: 기공유·기색인 URL 보존) 이중 파싱. dreamDB 미커버 시 카테고리 템플릿 조립+kw 시드 번호 생성(139개 동일 결과 금지). **보안 요건 필수**: kw는 textContent만(index innerHTML 13곳 원문 삽입 금지), cat 8종 화이트리스트(불일치=change). 보강: 해몽 결과에 상세 페이지·관련 꿈 링크 렌더(막다른 골목 해소), keywordMap 어근 20여 개 보강.
2. **네이버 서치어드바이저+Daum 등록**: 반나절로 미개척 유입 채널 전체가 열리는 유일 항목.
3. **공유 실질화**: Kakao SDK 실로드+feed 타입 전환, og:image(기본 1장→키워드군 10~20종), 공유 문구에 결과 포함, `utm_source=share_kakao`. 검색 외 유일한 무료 신규 유입 루프.
4. **서버사이드 회전**(축②): 사용자·크롤러 모두에게 실제 신선도.
5. **내 꿈 서랍(localStorage)** + 토요일 로또 추첨 리듬: 최초의 리텐션 장치. manifest.json으로 홈 화면 추가 안내.
- 계측 전제: GA4 커스텀 이벤트 7종(dream_search / haemong_start / lucky_view / share_click / related_click / cta_lucky_click / saju_open) 공통 스니펫 — **수리 배포 전 기준선 3~7일(상한 7일) 확보. 수리 코드는 기준선 기간 중 배포 금지**(§3 W1-5 게이트).
- 품질 보정(테마는 **다크 신비주의 유지** 확정): memimo 다크 재스킨+회유 순서 재배열, 페이지당 금색 CTA 1개 원칙, 푸터 대비 0.45+, nav 레이블 통일, guide 고아 6종 등재·개수 동기화, 커스텀 404(검색창+인기 꿈 5개).

**기각된 대안**: 라이트 테마 전환(139개 인라인 CSS 전면 수정 — 1인 운영 비용 대비 효익 없음, 다크가 도메인 정서·차별화에 부합) / localStorage 재방문 감지를 주지표로(인앱브라우저 단절 — GA4 기본 지표가 주).

### 축⑤ 수익화

**확정안 — "증설이 아닌 교체" + 병행 실행**
1. **AdSense**: 확인 A(콘솔 등재 도메인·상태)·D(Vercel 플랜) 회신 **즉시 응급처치와 병행**(공수 1h — 활성화 작업을 하루도 막지 않으므로 순서 논쟁 자체가 무효). 분기: 게재 가능→유닛 이식 / 불가→커스텀 도메인(연 1.5~2.2만원, 유일한 고정비) 구입+구 URL 301 일괄+재등록, 이때 Cloudflare Pages 이전 동시 실행(Hobby 약관 리스크 해소). 도메인 시나리오의 실작업은 §3 W2-0에 태스크화.
2. **배치 원칙(운영 규칙으로 문서화)**: 상세 페이지는 AdFit 중단 슬롯을 AdSense 인아티클로 **교체**("상황별 해석" 직후 = 정독 최심 지점) — 페이지당 총량 유지로 UX 중립·단가 상승. guide 인피드 1, index는 결과 섹션 아래 1(입력 퍼널 위 금지). 첫 뷰포트 광고 1개까지 / CTA 반경 90px 내 광고 금지 / ba.min.js 페이지당 1회 / 행운번호 블록과 광고 동일 카드 금지(사행성 오인 방지). Auto ads·앵커는 AdFit 병행정책 원문 확인 전 **보류**.
3. **회유 구간 재배열**: CTA→비슷한 꿈→광고→memimo→광고→공유→광고. 광고 수 불변, 스크롤 심화로 하단 viewability 상승. memimo_click 기추적이므로 전후 2주 A/B 비교 가능.
4. **AdFit 유닛 재편**: 320×50 위주→320×100/300×250 고단가 유닛(콘솔 작업 0원). 초기 2주 보수 배치 후 정책센터 모니터링.
5. **다각화(중기)**: 카카오톡 채널("오늘의 꿈해몽" 발송 = 재방문 자산, 무료 한도 확인 후) → 쿠팡파트너스(사용자 가입 승인 필요, 대가성 고지 의무, 사행성 연관 상품 금지) → 사주 유료화(데이터 이후). 이메일 리스트는 **기각**(사업 트랙 판정: 비로그인 모바일 전환 <1%). 사업 트랙이 대안으로 권한 **웹푸시(OneSignal 무료 티어)는 카카오톡 채널과 역할 중복(재방문 푸시)이므로 채널 성과 확인 후 보완재로만 재검토 — 유보**로 기재.

**기각된 대안**: AdSense를 1개월차 최우선 단독 트랙으로 — 트래픽을 만들지 않으므로 병행으로 조정(목적함수 차이일 뿐 사실 충돌 아님). Auto ads 전면 개방 — AdFit 4유닛과 밀도 초과·정책 리스크. Vercel Pro 전환(월 $20) — 도메인 도입 시 CF Pages 이전이 0원 대안.

6. **도메인 구입 승인**: 확인 A에서 게재 불가 확정 시, 연 15,000~22,000원 지출 승인 여부(승인 시 W2-0 발동).
7. **쿠팡파트너스 가입**: 외부 서비스 가입은 실행 행위 — 가입·고지문 게시 승인 여부.
8. **LLM 유료 사용 여부**: 무료 티어(0원) vs 유료(월 500~1,000원).
9. **사주 유료화 착수 시점**: 본 보고서는 v1 무료를 확정 — 트래픽 데이터 확보 후 유료화(통신판매업 신고·환불 규정 수반)를 진행할지는 사용자 결정 사항.
