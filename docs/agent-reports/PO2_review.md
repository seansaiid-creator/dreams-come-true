## 1. 지적 사항 (8건)

### 지적 1 [수정필수] W1-5·W1-6의 "선행: 없음"이 기준선을 오염시킨다 — 배포 게이트 누락

- 문제: PLAN P0의 확정 순서는 "①계측 → ②기준선 → ③수리 배포"다. 그런데 초안 W1-5(index 핸들러)는 선행이 "없음"이고, W1-3과 "동일 배포 가능"한 D0 배포 흐름에 얹힐 수 있다. 핸들러가 D0에 배포되면 기존 `?dream=` 링크 139개가 **기준선 수집 기간(W1-2) 중에 동작하기 시작**해, 측정하려던 "CTA 클릭 후 이탈률" 기준선 자체가 오염된다. W1-6 완료 기준("임의 10페이지 클릭 시 상이한 결과")도 배포를 전제한 문구라 같은 함정이 있다.
- 수정안 (문안 제시):
  - W1-5: "선행: 없음" → **"선행: 없음(구현·로컬 검증). 단 배포는 W1-12에만 포함 — D0 배포(W1-1·3·4)에 절대 편승 금지(기준선 오염)."**
  - W1-6 완료 기준: "임의 10페이지 클릭 시…" → **"로컬 프리뷰에서 임의 10페이지 클릭 시 키워드별 상이한 결과(배포 검증은 W1-12에서)."**
  - W1-12에 한 줄 추가: **"W1-5·W1-6은 이 배포에서 최초 공개된다."**

### 지적 2 [수정필수] 2~4주차 공수 합계 오기: "7~9일"이 아니라 10~12일

- 문제: W2-1(4~5) + W2-2(1) + W2-3(1~2) + W2-4(1) + W2-5(1) + W2-6(1) + W2-7(1) = **10~12일**. 초안 표기 7~9일은 산술 오류다. 1인 운영자가 3주 창(약 15근무일)에 10~12일 순공수는 다른 일이 하나만 끼어도 무너지는 일정이며, 과소 표기는 사용자의 착수 판단을 왜곡한다.
- 수정안: 합계를 **"10~12일"**로 정정하고, 완충 문안 추가 — **"임계 경로는 W2-1→W2-2(자동화가 이관에 종속)뿐이다. 일정 압박 시 W2-3(공유)·W2-5(내 꿈 서랍)·W2-7(홈 품질)은 5주차 이후로 순연 가능 — 순연해도 다른 태스크의 선행 조건을 깨지 않는다."**

### 지적 3 [수정필수] W1-3 완료 기준 "sitemap loc=145"는 자기모순 — 정답은 144

- 문제(코드 검증 근거): 미등재 41파일 중 index_ad_optimized.html은 **같은 주차 W1-4에서 301 처리되는 파일**이다. 301 대상을 sitemap에 등재하면 GSC에 "리디렉션 페이지를 sitemap에 제출" 오류가 새로 생긴다. 41을 전부 더해야 145가 되므로, "loc=145"라는 완료 기준은 index_ad_optimized 등재를 강제하는 셈이다.
- 수정안: W1-3 완료 기준을 **"sitemap loc=144 (dream 40 추가 등재, index_ad_optimized는 301 대상이므로 등재 금지), lastmod 실값, GSC 제출 확인"**으로. §1 C3에도 괄호 주석 1줄: "(등재 대상은 이 중 40, index_ad_optimized는 301)".

### 지적 4 [수정필수] "기본 가정"인 도메인 시나리오의 실작업이 To-do에 없다

- 문제: §6은 "*.vercel.app 게재 불가"를 **기본 가정으로 채택**했다. 그런데 그 가정이 실현됐을 때의 작업 — 도메인 구입→DNS 연결→구 URL 301 일괄→ads.txt·GSC·서치어드바이저·AdSense 재등록→Cloudflare Pages 이전 — 이 §2-⑤에 서술만 있고 To-do 항목·공수·선행이 없다. W1-11은 "승인 요청 상신"에서 끝난다. 기본 가정 경로가 실행 계획에 구멍인 셈이다.
- 수정안: 조건부 태스크 신설 — **"W2-0.(조건부: 확인 A 불가 판정+§5-B-6 승인 시) 도메인 전환 패키지 — [운영+개발] / 1일 / 선행: W1-11 분기 확정, 가능하면 W2-1 착수 전 / 완료: 신 도메인 200 응답, 구 URL 전수 301, ads.txt·GSC·서치어드바이저 재등록, CF Pages 서빙 확인."**
- 순서 근거 1줄 추가 권장: **"도메인 확정을 W2-1(11ty) 앞에 두면 site URL이 빌드 변수 1곳이 되어 canonical·sitemap·og:url 145개 재수정이 통째로 사라진다. 도메인 확정 전에 이관하게 되면 site URL 변수화만 해두고 값은 나중에 교체."**

### 지적 5 [권고] dream 페이지 내부 깨진 related-links 39종/45페이지가 최대 4주간 방치된다

- 문제: W1-9는 홈(searchIndex·randomPool·인기꿈)과 guide만 수리하고, C2의 본체인 **상세 페이지 안의 깨진 상대링크 39종은 W2-1 링크체커(2~4주차)까지 살아 있다**. UIUX §2-2는 "related-links 안의 깨진 것만이라도 우선 치환"을 P0로 못박았는데 초안에서 이 부분 채택이 누락됐다. 45페이지의 회유 클릭이 그동안 계속 404로 샌다.
- 수정안: W1-9 범위에 편입 — **"…+ dream 페이지 related-links 내 깨진 대상 39종 실존 파일로 치환/제거(스크립트 추출→sed, +1h — W1-6과 같은 139파일 패스에 편승). 전체 링크 무결성의 최종 보증은 W2-1 링크체커."** 공수 3h→4h로 정정.

### 지적 6 [권고] BIZ의 웹푸시 대안이 기각 사유 없이 소실 + 인용 왜곡

- 문제: BIZ §3은 "이메일 전환 낮음(<1%) → **웹푸시(OneSignal 무료 티어)가 더 적합**"이라고 했다. 초안 §2-⑤는 "이메일 리스트는 후순위 기각(비로그인 모바일 전환 <1%)"만 남기고 BIZ가 실제로 권한 웹푸시를 무언급 소실시켰다 — 기각이면 사유가, 채택이면 목록 등재가 있어야 한다. 현재 문장은 BIZ가 이메일을 권한 것처럼 읽히는 인용 왜곡이기도 하다.
- 수정안: §2-⑤ 다각화 문장을 — **"…쿠팡파트너스 → 사주 유료화(§6). 이메일 리스트는 기각(BIZ 판정: 비로그인 모바일 전환 <1%). BIZ가 대안으로 권한 웹푸시(OneSignal 무료 티어)는 카카오톡 채널과 역할 중복(재방문 푸시)이므로 채널 성과 확인 후 보완재로만 재검토 — 후보 목록에 유보로 기재."**

### 지적 7 [권고] UIUX nav 일관성 지적(§2-4)이 통째로 누락

- 문제: 상세 페이지 nav 레이블("해몽하기/해몽가이드/소개")과 홈·guide("홈/꿈 사전/소개") 불일치, 상세 페이지 guide 링크의 잘못된 `active`, 상세→사전 진입 링크 부재("128가지 꿈 전체 보기") — UIUX가 회유 순환 루프의 구성 요소로 제시한 항목인데 초안 어디에도 없다. 무공수에 가까운 항목(템플릿 1곳)이라 누락이 아깝다.
- 수정안: W2-1 완료 기준의 템플릿 일괄 반영 목록에 추가 — **"nav 레이블 '홈/꿈 사전/소개' 통일·상세 페이지 active 오표기 제거·related 섹션 하단 '전체 꿈 사전 보기→guide' 링크"** (별도 태스크 불요, 한 줄 편입).

### 지적 8 [의견] W2-6(광고 교체)과 W2-1(11ty)의 실행 순서 미명시

- 문제: W2-6이 이관 전 원시 HTML에서 실행되면 139파일 광고 마크업 수정이 이관에서 한 번 더 재현돼야 하고(검증 2단계 대조표 부담 증가), 이관 후라면 템플릿 1곳 수정으로 끝난다. 초안은 두 태스크의 상대 순서를 지정하지 않았다.
- 수정안: W2-6 선행에 **"W2-1(이관 후 템플릿에서 실행 — 원시 HTML 선반영 금지)"**를 추가. 단, 확인 A가 "게재 가능"으로 빨리 확정되고 이관이 지연되면 index 1페이지 유닛 이식(W1-11)까지만 선행하고 139페이지 확장은 이관 후로.
