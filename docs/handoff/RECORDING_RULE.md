# 기록 규칙 — 모든 창 공통 (2026-09-04)

> 이 블록은 각 창의 프롬프트에 그대로 붙여 넣는다. 원본은 이 파일이다.

```
【기록 규칙 — 모든 창 공통】
이 창에서 나온 결론은 대화에만 남기지 마라. 창을 닫으면 대화는 사라지고,
다른 창은 이 대화를 절대 볼 수 없다. 세션 간 공유되는 것은 레포 파일과 메모리뿐이다.
파일에 안 적힌 것은 없는 것과 같다.

무엇을 어디에 적는가:
- 사건·문제·교훈(터진 일, 오진, 수정한 것) → docs/WORKLOG.md 상단에
  "### [상태] 제목 (날짜)" 형식으로. 증상 → 원인 → 처리 → 교훈 순서
- 하기로/안 하기로 정한 것 → docs/DECISIONS.md. 이유와 날짜를 함께
- 운영 기준·전략의 변경 → OPERATIONS.md 해당 절
- 이 창의 현재 상태·대기 작업 → docs/handoff/{내 창}.md 를 갱신
  (다른 창의 핸드오프는 읽기만. 지시를 남길 때만 그 창의 "대기 작업" 절에 추가)

어떻게 적는가:
- 수치는 docs/metrics/latest.md 의 값만 쓴다. 직접 계산한 값을 적지 않는다
  (갱신: node scripts/ga/metrics.mjs · ⚠️ 표시된 비율은 표본 부족이므로 인용 금지)
- 그 밖의 수치는 확인 방법과 함께. 추측이면 "추측"이라고 명시. 확인 못 했으면 "확인하지 못했다"
- 내가 틀렸던 것도 적는다. 정정 이력이 다음 창의 실수를 막는다

언제 적는가:
- 작업이 다 끝났을 때가 아니라 결론이 날 때마다. 미루면 유실된다

커밋:
- 파일 경로를 명시해서 add. git add -A 금지(과거 이것으로 광고 141파일이 되살아난 사고)
- STATUS.md는 자동 생성물이므로 커밋하지 않는다
```
