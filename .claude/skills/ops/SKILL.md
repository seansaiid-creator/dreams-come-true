# 주간 운영 사이클

먼저 OPERATIONS.md를 읽어라. 모든 판단 기준·확정 규칙·컨펌 필수 항목이 거기 있다. 그 규칙과 충돌하는 제안을 하지 마라 (규칙 변경이 필요하면 변경 자체를 안건으로 올려라).

## 실행 순서
1. **데이터 수집**
   - `ga4/` 폴더의 최신 CSV 확인 (없거나 오래됐으면 운영자에게 내보내기 요청: 트래픽 획득 + 페이지 및 화면, 최근 7일)
   - STATUS.md (자동 헬스체크 결과) 확인
   - `git log --oneline -20`으로 자동 발행·회전 커밋이 정상 주기로 찍히는지 확인
   - content-queue/queue.json 잔량 확인
2. **분석**: KPI 표(OPERATIONS.md §3) 기준으로 전주 대비 변화 산출. 특히: 퍼널(cta_lucky_click→lucky_view), 신규 발행 페이지의 조회 발생 여부, 구글 유입 비중 변화, 이상 급락/급등.
3. **제안**: 이번 주 액션 최대 3건. 각각 기대 임팩트 / 공수 / 리스크 / OPERATIONS.md 로드맵과의 연결을 명시. 데이터가 근거인 제안을 우선하고, 근거 없는 제안은 "가설"이라 표기.
4. **컨펌 대기**: §5 컨펌 필수 항목은 반드시 운영자 승인 후 실행. 승인된 것만 구현→검증→배포.
5. **기록**: OPERATIONS.md §6 로드맵 체크박스와 KPI 표를 갱신하고 커밋. 중요한 결정은 메모리(dreams-project-state)에도 반영.

## 발행 큐 관리
- 검수완료 잔량이 2주치(현 단계 주3 기준 6건) 미만이면 초안 추가 생산을 제안하라.
- 초안 주제는 ①GA4 dream_search result_count=0 검색어 ②기존 상위 페이지 패턴(일상 소재 롱테일) ③계절·시기 이슈 순으로 발굴.
